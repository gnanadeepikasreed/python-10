
# Campus Event Financial Planning

## Description
This project analyzes the financial requirements of a college event by calculating expenses, sponsorship, participant contributions, and break-even registrations.

## Features
- Calculates venue and equipment costs.
- Calculates catering and transport costs.
- Calculates certificate expenses.
- Calculates total event cost.
- Calculates participant contributions.
- Checks sponsorship shortfall.
- Calculates remaining amount or deficit.
- Finds minimum registrations required to break even.

## Concepts Used
Variables, data types, operators, conditional statements, and basic calculations.

## Language
Python 3

## How to Run
python Campus_Event_Financial_Planning.py
